## 1. Obtener tu API key

1. Ingresá a [app.corredor.ar](https://app.corredor.ar)
2. Andá a **Configuración → Integraciones → API**
3. Generá una nueva API key con los permisos necesarios

<Warning>
Guardá tu API key en un lugar seguro. No la compartas ni la incluyas en el código fuente.
</Warning>

## 2. Realizar tu primera llamada

<CodeGroup>

```bash cURL
curl -X GET "https://api.corredor.ar/v1/properties" \
  -H "Authorization: Bearer <tu-api-key>" \
  -H "Content-Type: application/json"
```

```typescript SDK
import { CorredorClient } from '@corredor/sdk';

const client = new CorredorClient({ apiKey: process.env.CORREDOR_API_KEY });

const properties = await client.properties.list({ limit: 20 });
console.log(properties.data);
```

```python Python
import requests

response = requests.get(
    "https://api.corredor.ar/v1/properties",
    headers={"Authorization": "Bearer <tu-api-key>"}
)
print(response.json())
```

</CodeGroup>
