## @corredor/sdk

El SDK oficial de Corredor CRM está disponible en npm como `@corredor/sdk`. Está construido sobre la especificación OpenAPI 3.1 de la API y provee tipado completo en TypeScript.

## Instalación

<CodeGroup>

```bash npm
npm install @corredor/sdk
```

```bash pnpm
pnpm add @corredor/sdk
```

```bash yarn
yarn add @corredor/sdk
```

</CodeGroup>

## Características

- **TypeScript first**: todos los tipos generados desde la especificación OpenAPI
- **Auto-completado**: soporte completo en VS Code, WebStorm y otros IDEs
- **Paginación automática**: helpers para iterar sobre colecciones paginadas
- **Manejo de errores**: clases de error tipadas por código de respuesta
- **Tree-shakeable**: importá solo lo que necesitás

## Versiones

El SDK sigue versionado semántico. La versión del SDK coincide con la versión mayor de la API.

| SDK       | API versión |
|-----------|-------------|
| `^1.0.0`  | `v1`        |
