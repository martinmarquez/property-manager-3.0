La API de **Corredor CRM** te permite integrar tu aplicación con la plataforma líder de CRM inmobiliario de Argentina. Gestiona propiedades, contactos, leads y sincroniza publicaciones con los portales inmobiliarios más importantes.

## Características principales

- **Multi-tenant**: soporte completo para inmobiliarias, brokers independientes y empresas.
- **Sincronización de portales**: publicación automática en MercadoLibre, Proppit, ZonaProp y más.
- **Webhooks**: recibe eventos en tiempo real para leads, cambios de propiedades y más.
- **Paginación por cursor**: navegación eficiente sobre grandes conjuntos de datos.
- **Rate limiting por plan**: desde 60 req/min (Basico) hasta 2000 req/min (Enterprise).
